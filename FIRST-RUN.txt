BOOK CAPTURE AI v0.5 - FIRST RUN

1. Open Kindle for Web / an ebook reader / browser on Windows.
2. Run BookCaptureAI.exe.
3. Click "ウィンドウ更新" and choose the ebook window.
4. Click "画面範囲を選択" and drag around the whole visible book area.
5. Choose the page-turn key (Kindle is often ← or → depending on layout).
6. For a two-page spread, keep "見開きを中央から2ページに自動分割する" ON.
7. Japanese books: use "右 → 左". Western/left-to-right books: use "左 → 右".
8. Keep "上部のKindleヘッダーを除去" ON. Default 8%.
9. Keep "下部のKindleフッターを除去" ON. Default 6%.
10. Click "キャプチャ開始".
11. Original screenshots always remain untouched in images/.
12. Clean split pages are saved in images-split/.
13. PDF / searchable PDF / OCR TXT are generated from the clean pages.

If using a normal one-page Kindle view:
- Turn spread split OFF.
- Header/footer removal can remain ON.
- Clean pages are saved in images-clean/.

OCR:
- Tesseract OCR + Japanese/English language data are bundled.
- No separate OCR installation is required.
- OCR runs locally on this PC.

Tuning:
- If some Kindle header remains, increase the top percentage slightly.
- If body text is cut off, decrease the top percentage.
- If "読書速度を学習中…" or position/progress remains, increase the bottom percentage slightly.
- Start with Top 8% / Bottom 6%.

Safety / rights:
- This app does not remove DRM or bypass screenshot protection.
- Use only for content and purposes you are authorized to copy.
